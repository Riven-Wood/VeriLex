# 在 Mac 上安装 VeriLex

本次安装包适用于 Apple Silicon（M 系列芯片）Mac，最低系统要求为 macOS 12。不支持 Intel Mac 或 Windows。

1. 打开 [v1.0.0 发布页](https://github.com/Riven-Wood/VeriLex/releases/tag/v1.0.0)，下载 `VeriLex-1.0.0-macos-arm64.zip`。
2. 双击解压，将 `VeriLex.app` 拖到访达左侧的“应用程序”。
3. 双击打开 VeriLex。已有安装版时，先保存文书并正常退出旧应用，再替换；保留应用数据目录。
4. 进入“设置 → 模型”，添加模型连接并测试。密钥只填写在应用内对应输入框。
5. 选择工作目录，在对话或法律工作入口添加材料后使用。

VeriLex 没有 Apple Developer ID 签名和公证。如果系统提示无法验证开发者，在确认下载来源后，按苹果菜单“系统设置 → 隐私与安全性”中针对 VeriLex 的提示决定是否“仍要打开”。如果提示文件损坏或会损害电脑，停止打开并核对下载来源，不要关闭整机安全检查。

系统操作以 [Apple 官方指引](https://support.apple.com/zh-cn/102445)为准，不同 macOS 版本显示可能不同。

首版使用发布页手动安装，未提供应用内自动更新清单。程序内的在线更新检查失败不代表本地安装失败。云模型、法律数据源等第三方服务需自行开通；不随安装包附送。
