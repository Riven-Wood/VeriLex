# v1.0.0 发布验证

日期：2026-10-27。安装包目标为 Apple Silicon macOS。本次是首个公开发行版本，包含已知未通过的检查，不宣称所有功能与平台均已验收。

## 已完成

- 五处发行版本与程序后台版本统一为 1.0.0，发布版本检查通过。
- 前端类型检查和生产构建、本机后台打包及 macOS arm64 原生应用构建通过。
- 从最终 ZIP 解压应用后，macOS 本机签名完整性检查通过；这不是 Apple Developer ID 签名或公证。
- 实际解压包的后台在独立空数据目录启动，健康接口返回版本 1.0.0。没有模型、外部工具连接或用户文件夹；仅包含首次初始化的两个内置技能。
- 实际解压包完成虚构合同预览、首次 Word 批注与审查意见书生成检查；原始合成合同保持不变。随包 ima MCP 的本机握手检查通过，未调用真实 ima 服务。
- 发布的 Word 浏览器资源共 88 个受锁定校验的文件，完整目录散列与 `renderer-lock.json` 一致。
- 发布源码不携带旧提交历史、本机状态、私钥、真实案件、内部开发交接记录和截图。对常见密钥格式的检查命中均为测试中的虚构凭据或示例地址，未发现实际密钥。
- 源码暂存检查和发布文件 SHA-256 校验完成。

## 未通过或未完成

前端全量检查结果为 **1641 通过、10 失败**：

- `desktop/tests/litigation-flow.test.tsx`：4 项，涉及旧返回入口、案件讨论入口和运行状态下的页面交互。
- `desktop/tests/litigation-updates.test.tsx`：5 项，涉及旧争议焦点页签、再生成与结果刷新预期。
- `desktop/tests/timeline-streaming-perf.test.tsx`：1 项，仍期望审批到来时出现旧的跳转入口，当前审批卡已移至输入区。

其中部分预期对应此前已经调整的界面；本次没有通过删除测试或恢复旧界面来掩盖失败，也没有认定这些失败全部不影响产品。

后台全量检查在受限执行环境中得到 **620 通过、11 失败**，随后因长时间停滞主动中断，不能视为一次完整检查。失败均发生于本机终端/后台任务路径，输出包含 `sandbox-exec: sandbox_apply: Operation not permitted`。在正常本机环境重新运行受影响模块，并加入健康接口和来源锁检查，**30 项通过**。没有据此声称后台全量通过。

本次没有重新执行所有真实模型流程、全部原生界面操作、中文输入法、Microsoft Word/WPS、Windows、Intel Mac、Linux 或所有旧版 macOS 的完整验收。PDF 转换需要本机 LibreOffice，复杂 Word 对象与跨软件排版仍须核对。

## 发布方式

首版以本机核验过的 ZIP 手动发布；未发布自动更新清单或更新签名。仓库中的历史自动发布工作流保留供后续开发参考，GitHub Actions 当前未启用；不能把这些工作流视为可立即完成本版自动构建和签名发布的配置。后续启用前需补齐 Word 资源准备、剩余测试问题与独立发布凭据配置。

本次对外公开的许可证为 PolyForm Noncommercial 1.0.0；第三方组件保持各自原始许可证。文件校验值用于核对下载内容，不替代 Apple 平台公证，也不证明 AI 输出的专业正确性。
