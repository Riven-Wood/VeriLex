# v1.1.1 发布验证

本版在 v1.1.0 的公开源码基础上加入 26 项技能及工作流入口。首次启动在本机数据目录初始化；已存在的同名技能不覆盖，删除后不因重启恢复。技能文本配套资料读取只允许随包且内容未改动的文件，拒绝路径越界、符号链接、二进制和超长文件。

- 后台技能发现、初始化、同名保留、删除不复活、许可文件、配套资源读取及隔离检查、技能管理 API 和健康检查通过。对最终开发源码和公开发布源码均运行了相关自动检查。
- Mac 安装包解压后验证临时签名完整性，在空白测试目录启动后台，核对版本、技能列表及所有随包资源文件；合成合同和 ima 插件本地握手通过。
- 公开来源、固定版本和各自许可证载于 `THIRD_PARTY_NOTICES.md` 与每个技能目录；Apache、MIT、CC BY-NC 和 AGPL 覆盖的内容保持各自许可。17 个中国法律工作流是 VeriLex 编写的入口，使用选取的公开上游材料；其他技能亦可能与用户个人收藏的改写版不同。
- 未逐项验证技能在真实模型、企查查或其他第三方服务、OfficeCLI、外部脚本、Word/WPS、中文输入法及 Windows 上的业务行为。技能列表可见不等于全部流程已经验证。
- 本版仅提供 Apple Silicon Mac 安装包，未经 Apple Developer ID 签名与公证；不提供线上自动更新签名包。文件脱敏结果可能在修订记录中保留原文，对外分享前须检查、接受修订并另存。
