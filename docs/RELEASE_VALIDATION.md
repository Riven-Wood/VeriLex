# v1.1.0 发布验证

本版是基于 2026-11-01 的 Mac 开发状态整理的公开快照，与 v1.0.0 公开历史衔接。仅发布 Apple Silicon macOS 安装包；Windows 后续改动未在本版整合或真机验证。

- 发布候选使用锁定依赖构建前端、后台和 macOS arm64 应用；Word 引擎资源包的 88 个文件与源码锁定的哈希树一致。Mac 压缩包解压后通过签名完整性检查，空白测试数据下启动后台并核对版本；合成合同的预览、首次批注和报告，以及 ima 插件本地握手检查通过。
- 对版本修改前的开发源码运行后台全量检查：3998 通过、3 跳过；版本调整后对发布候选的健康检查另行通过。两项 fork 警告不表示真实并发环境已经全面验证。
- 桌面端全量检查为 1735 通过、4 失败。两项设置分类检查仍按旧分类列表断言；一项联网检查因读取次数变化失败，单独核对拒绝联网后切换页面返回仍为关闭；一项模型连接删除检查先收到连接状态未同步提示，任务进行中删除提示尚需进一步核验。
- 未完成真实模型与第三方服务的全面检索、所有原生界面交互、Microsoft Word/WPS 兼容性、中文输入法、真实旧版本跨版本升级以及 Windows、Intel Mac、Linux 的完整验证。复杂文档和脱敏结果必须人工复核。
- Mac 应用以临时签名完成完整性检查，未经 Apple Developer ID 签名与公证；本版没有应用内自动更新签名包，需在 GitHub 发布页手动下载。

文件脱敏导出可能在修订记录中保留原文，对外分享前应检查并接受全部修订、另存，且再次核对结果。模型和外部工具可能向相应服务发送完成任务所需的信息。
